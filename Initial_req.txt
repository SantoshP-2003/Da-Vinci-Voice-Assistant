# Project: Voice-Activated Multilingual Educational RAG Assistant

## Project Objective

Develop a scalable AI-powered educational assistant that enables students to ask academic questions through voice in multiple Indian languages and receive intelligent responses in both text and speech. The assistant will use Retrieval-Augmented Generation (RAG) to answer questions from educational documents, providing accurate, context-aware, and personalized learning support while improving accessibility for all students, including visually impaired users.

# Core Workflow

1. User selects a subject (optional).
2. User uploads educational documents (optional).
3. User clicks the microphone button.
4. Dialog box appears which records user's input.
5. Detect spoken language.
6. Convert speech to text using Faster-Whisper.
7. Search ChromaDB for relevant document chunks.
8. Retrieve the most relevant educational context.
9. Send the retrieved context and user query to the Gemini API.
10. Generate a context-aware response.
11. Convert the response into speech.
12. Display the response in the chat interface.
13. Play the spoken response.
14. Save the conversation history.
